Overview

Foley Logistics is a crane truck hire and heavy freight transport company based in Gold Coast, Australia. They operate a large fleet of vehicles across multiple depots and need strict pre-start safety checks before every shift.

I built the Foley Pre-Start plugin — a fully custom WordPress plugin that digitises the entire vehicle inspection workflow, from driver login to manager sign-off.

The Challenge

Pre-start inspections were done on paper. This created several problems: forms were frequently lost or incomplete, fault reports could sit unread for days, and there was no reliable audit trail for compliance purposes.

The client needed a solution that worked on mobile devices at depot sites, required minimal training for drivers, and gave managers real-time visibility over the fleet's condition.

The Solution

I built a custom WordPress plugin (v2.3.2) that handles the complete inspection lifecycle:

  • Driver Portal — Drivers log in via a branded portal and complete digital checklists tailored to their assigned vehicle type (rigid, semi, crane).
  • Digital Checklists — Each inspection covers brake checks, lights, fluid levels, tyres, and crane-specific items. Drivers can attach photos to fault entries.
  • Fault Reporting — Faults are flagged in real time and routed to the relevant manager dashboard, with severity classification.
  • Digital Signatures — Both driver and manager sign off digitally, creating a timestamped audit record.
  • Manager Dashboard — Fleet overview with live fault status, inspection history per vehicle, and exportable compliance reports.
  • Action Scheduler — Background jobs handle notification dispatch, reminder emails, and automated escalation for unresolved faults.

The plugin is built on WordPress with no third-party SaaS dependency — keeping all inspection data on the client's own server for compliance and privacy.
