Overview

GATAC is an automotive parts distributor operating across the USA, EU, and UK. They needed a custom B2B distribution portal embedded inside Shopify Admin — a system where authorised distributors could place orders using customer-specific pricing that doesn't exist on the public storefront.

I built both the custom Shopify storefront theme and the embedded Next.js 14 portal from the ground up, integrating deeply with Shopify's Admin API and app proxy system.

The Challenge

Shopify's native B2B features didn't support GATAC's pricing model. Each distributor needed its own price list, and sales reps needed to create draft orders on behalf of customers using those custom prices — all without touching the public storefront.

The portal also needed to live inside Shopify Admin as an embedded app, meaning authentication had to run through Shopify SSO (App Bridge) rather than a separate login system.

The Solution

I built a Next.js 14 App Router application embedded in Shopify Admin via app proxy. Key features:

  • Custom Price Lists — Distributors are assigned price lists with customer-specific pricing overrides.
  • Draft Order Creation — Sales reps select a customer, apply their price list, add products, and create Shopify draft orders in one flow.
  • Shopify SSO — Authentication runs entirely through Shopify App Bridge — no separate login system.
  • Custom Storefront Theme — B2B redirect flows built into the theme, keeping retail and wholesale traffic separated.
  • Multi-Region Support — USA (Phase 1) with EU and UK region support built in for future rollout.

Built with Polaris (Shopify's design system), the portal feels native inside Shopify Admin — no visual context-switching for the team.

What I Built

Embedded App + SSO

A Next.js App Living Inside Shopify Admin

Engineered a Next.js 14 App Router application that runs inside Shopify Admin through the app proxy, authenticating entirely via App Bridge SSO — no separate login to build or maintain. Each distributor's custom price list resolves server-side, so wholesale pricing never leaks to the public storefront.

Shopify Admin API

One-Flow Draft Order Engine

Reps pick a customer, apply their price list, add products, and push a live Shopify draft order from a single screen — wired straight to the Admin API. Collapsing a 20-minute manual process into 3 minutes was an integration problem, and I solved it with no third-party order tooling.
